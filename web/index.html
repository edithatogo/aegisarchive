AegisArchive Guide & Ethical Principles

1. Server Preservation by Design

AegisArchive enforces human-cadence browsing, decorrelated exponential backoff, and real-time latency monitoring. It automatically slows down when target servers experience load spikes, ensuring servers are protected against accidental denial-of-service (DDoS).

2. ISO 28500 WARC/1.1 Archival Standard

All captured HTTP request and response records are serialized into standard WARC containers accompanied by 11-field CDX indexes. Content-addressable SHA-256 deduplication ensures identical styles, images, and documents write lightweight revisit records, reducing storage footprints by up to 70%.

3. Replaying Captured Archives Offline

You can verify and browse captured archives completely offline by clicking the Offline WARC Viewer button. It loads your .warc file locally inside an isolated, sandboxed viewer with zero internet required.

4. Cross-Platform Standalone Execution

AegisArchive runs on Windows, macOS, and Linux without administrator permissions or external package installations. Use START_MAC.command, START_WINDOWS.cmd, or START_LINUX.sh to launch anywhere.
