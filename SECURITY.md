# Security Policy: AegisArchive

## Supported Versions
Only the latest release on the `main` branch receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security and integrity of digital preservation tools seriously. If you identify a security vulnerability or sensitive leak in AegisArchive:

1. **Do not open a public GitHub issue.**
2. Please privately disclose the issue by contacting the maintainer via GitHub Security Advisories at https://github.com/edithatogo/aegisarchive/security/advisories/new.
3. Include a description of the issue, reproduction steps, and potential impact.

We commit to acknowledging receipt within 48 hours and providing a mitigation timeline.
