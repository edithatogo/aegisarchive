# Mirroring compatibility

The synthetic acceptance receipt qualifies the portable static scope on each
runner. HTML navigation and captured assets are supported offline when their
bytes were captured. Authentication requires an explicitly supplied session;
dynamic server-side behaviour is not reproduced. Resume and packaging depend on
their respective track receipts. Optional intelligence engines are separate
and do not expand the mirroring claim.

Run `python scripts/mirroring_acceptance.py --output artifacts/receipt.json` to
create a local, hash-bound receipt and `--check` to validate it.
