# Product Vision: AegisArchive

## Core Proposition
A zero-install, server-preserving web archiver and ISO 28500 forensic engine for high-fidelity offline replication, digital preservation, and resilient research.

## Key Target Users
1. **Digital Preservationists & Archivists**: Requiring pristine, ISO 28500 compliant WARC/1.1 records with CDX indexing.
2. **Researchers & Journalists**: Needing reliable, tamper-evident snapshots of web portals without complex server infrastructure.
3. **Institutional Teams**: Operating within restricted IT environments (zero admin rights, locked USB stations).
4. **AI Agents & Automated Systems**: Requiring polite, standardized web exploration tools via the Model Context Protocol (MCP).
